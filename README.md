# Machine Learning Experiments

This repository contains the Machine Learning experiments performed as part of my academic coursework.

## Experiments

### Experiment 1 — Data Pre-processing

**Objective:**
To perform data pre-processing on a raw dataset by handling missing values and applying normalization and standardization techniques.

**Topics Covered:**

* Handling missing values
* Data cleaning
* Normalization
* Standardization

### Experiment 2 — Exploratory Data Analysis and Visualization

**Objective:**
To perform Exploratory Data Analysis (EDA) on a dataset and visualize the data to understand its patterns, distributions, and relationships.

**Topics Covered:**

* Descriptive statistics
* Data distribution
* Data visualization
* Identifying patterns and relationships

### Experiment 3 — Regression Algorithms

**Objective:**
To implement and understand Linear Regression and Logistic Regression algorithms using a suitable dataset.

**Topics Covered:**

* Linear Regression
* Logistic Regression
* Model training
* Prediction
* Model evaluation

### Experiment 4 — Principal Component Analysis (PCA)

**Objective:**
To apply Principal Component Analysis (PCA) on a multivariate dataset to reduce its dimensionality, visualize the data in lower dimensions, and evaluate the amount of variance retained after transformation.

**Topics Covered:**

* Data standardization
* Dimensionality reduction
* Principal Component Analysis (PCA)
* Explained variance
* 2D visualization
* Variance retention

### Experiment 5 — Support Vector Machine (SVM)

**Objective:**
To implement and understand the Support Vector Machine (SVM) algorithm for classification using a suitable dataset and evaluate its performance.

**Topics Covered:**

* Hyperplane and margin
* Support vectors
* Linear and non-linear classification
* Kernel functions
* RBF kernel
* Feature scaling
* Model evaluation

### Experiment 6 — K-Nearest Neighbors (KNN)

**Objective:**
To implement the K-Nearest Neighbors (KNN) classification algorithm and evaluate its performance using a suitable dataset.

**Topics Covered:**

* K-nearest neighbors
* Distance-based classification
* Euclidean distance
* Feature scaling
* Classification
* Model evaluation

### Experiment 7 — Comparison of Regression Algorithms

**Objective:**
To compare the performance of different regression algorithms on a given dataset and identify the suitable algorithm for predictive modeling.

**Topics Covered:**

* Linear Regression
* Polynomial Regression
* Decision Tree Regression
* Random Forest Regression
* Support Vector Regression (SVR)
* MAE, MSE and R² evaluation
* Model comparison

### Experiment 8 — Comparison of Classification Algorithms

**Objective:**
To implement and compare multiple classification algorithms on a dataset and evaluate their performance using Precision, Recall, and Accuracy metrics.

**Topics Covered:**

* Logistic Regression
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbors (KNN)
* Naïve Bayes
* Precision
* Recall
* Accuracy
* Model comparison
