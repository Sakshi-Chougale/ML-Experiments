# Machine Learning Experiments

This repository contains the Machine Learning experiments performed as part of my academic coursework.

## Experiments

### Experiment 1 — Data Pre-processing

**Objective:**  
To perform data pre-processing on a raw dataset by handling missing values and applying normalization and standardization techniques.

**Topics Covered:**

* Handling missing values
* Data cleaning
* Normalization
* Standardization

### Experiment 2 — Exploratory Data Analysis and Visualization

**Objective:**  
To perform Exploratory Data Analysis (EDA) on a dataset and visualize the data to understand its patterns, distributions, and relationships.

**Topics Covered:**

* Descriptive statistics
* Data distribution
* Data visualization
* Identifying patterns and relationships

### Experiment 3 — Regression Algorithms

**Objective:**  
To implement and understand Linear Regression and Logistic Regression algorithms using a suitable dataset.

**Topics Covered:**

* Linear Regression
* Logistic Regression
* Model training
* Prediction
* Model evaluation
